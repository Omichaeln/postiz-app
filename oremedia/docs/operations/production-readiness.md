# Production-readiness gate (spec 25; ledger 7.g1)

Status as of 2026-09-24, from this repository and its local runs only (MySQL 8 and Redis local; no Temporal
server, no Railway, no provider accounts, no collector). **Verdict: not ready for the client pilot.** The
checklist below says which items are verified (and by what), which are open (and the risk), and which are not
applicable. Nothing here is verified by a deployed environment.

Legend: **verified** (how) · **open** (risk) · **n/a** (why).

# Calendar rules

- Cadence comes from the brand's channel guidance; when none is stated use at most one entry per channel per
  three days and say so in a `note` finding.
- The first entry of each channel introduces the campaign; the last one within the window closes it (offer
  deadline, recap or thank-you) when the objective is time-bound.
- Mandatory facts (legal wording, price, availability) appear in every entry that mentions the offer.
- Alternate themes across channels so the same message does not land on every channel on the same day unless
  the objective is a single-day launch.
- Format keys must exist in the brand's channel guidance for that provider (for example `square_1080`,
  `story_1080x1920`); do not invent format keys.

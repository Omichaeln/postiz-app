# Adaptation rules

Priority when shortening text (remove from the bottom of this list first):

1. Mandatory facts: legal wording, price, availability, contact details. Never removed.
2. The single CTA.
3. The primary benefit sentence.
4. Supporting proof sentences (each tied to a fact id).
5. Hashtags beyond the channel's guidance.
6. Decorative or transitional sentences.

Per-channel notes are written into `capabilityNotes` in plain language ("link removed: channel does not carry
links", "format substituted: story_1080x1920 → square_1080").
